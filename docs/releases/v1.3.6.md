# bmlsub 1.3.6

Released November 13, 2026.

## Qwen3-ASR transcription

bmlsub now supports `mlx-qwen3-asr` on Apple Silicon, with
`mlx-community/Qwen3-ASR-1.7B-8bit` as the default Qwen model.

The default `full` policy runs three jobs sequentially in Workstation
preprocessing and standalone `build trans`:

1. Whisper medium with direct full-length input.
2. Whisper large-v3-turbo with 240-second chunks and 5-second overlap.
3. Qwen3-ASR 1.7B 8-bit with direct full-length input.

The transcription menus also offer Qwen3 alone. Custom recipes can select
the Whisper or Qwen engine, and the Pipeline API selects the matching default
model when no model is specified.

## Full-length input and timestamps

Qwen receives the complete WAV in a single backend call. bmlsub does not
create external Qwen audio slices and rejects `chunked`, `both`, and manual
cuts for this engine. The upstream model library still processes long audio
in internal chunks. Its timestamps are labelled `audio_chunk`, not presented
as sentence- or word-aligned subtitle timing.

Native decoding metadata is retained. Token-limit truncation fails validation
instead of silently publishing an incomplete transcript. A repetition stop
produces a warning identifying the chunks that need review. Machine-generated
text remains a reference for human proofreading.

## Compatibility and recovery

- Existing jobs without an engine field continue to use Whisper.
- Custom saved jobs preserve engine, model, revision, language, and decoding
  settings during resume; invalid saved configurations produce explicit errors.
- Existing standard two-job `full` policies resume with the new third Qwen job.
- Qwen has an independent stage and output identity, with readable text export
  and reuse of valid completed artifacts.
- The package version participates in stage fingerprints. Upgrading to 1.3.6
  may therefore rerun stages previously recorded under an older tool version;
  normal output validation and backup behavior still applies.

On Apple Silicon, install or upgrade the `[transcription]` optional dependencies
to enable both ASR backends. The new default `full` policy performs an additional
model pass; select `quick`, `qwen3`, or `none` when that better matches the task.

## Validation

- Integration regression suite: 199 tests, with 198 passed and one unrelated
  real-font fixture test skipped.
- Full-recording Qwen test: a 23:58.048 Japanese recording completed through
  Pipeline registration, JSON output, text export, and second-run cache reuse.
  No external Qwen audio slices were created.
- Real three-model test: the default medium, turbo, and Qwen jobs completed
  in the required order on a short audio fixture; only the turbo job created
  an external chunk directory.
- Development and inference validation used the isolated `bmlsub-test`
  Conda environment.
